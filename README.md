# Вариант 4: Email Validator

## Задача
Простая проверка email (наличие @ и .).

## Уязвимости в тестах
- Тесты неполные: отсутствуют проверки граничных случаев.
- Нет обработки ошибок (например, деление на ноль, недопустимые значения).
- Не покрыты все ветки условий.

## Инструкции
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите тесты: `pytest tests/`
3. Запустите мутационное тестирование:  
   `mutmut run --paths-to-mutate=src/ --tests-dir=tests/`
4. Проанализируйте выжившие мутанты и улучшите тесты.
5. Стремитесь к mutation score ≥ 90%.
